# Contributing

Thank you for contributing to OpenShift on NVIDIA DSX Air.

## Contribution terms

This project is licensed under the [Apache License 2.0](LICENSE). Unless you
state otherwise, contributions that you intentionally submit for inclusion in
the project are provided under the same license.

This project uses the [Developer Certificate of Origin 1.1](https://developercertificate.org/)
instead of a contributor license agreement. By adding a `Signed-off-by` line to
a commit, you certify that you have the right to submit the contribution under
the project's license.

Create the sign-off with your real name and an email address associated with
the contribution:

```text
Signed-off-by: Your Name <your.email@example.com>
```

Most version-control clients can add this line when they create a commit. For
Git, use:

```sh
git commit --signoff
```

Follow the project's [development guide](docs/development.md) to set up the
environment and run the required checks before you submit a change.
